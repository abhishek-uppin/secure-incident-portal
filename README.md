# Secure Incident Portal

## Overview
Secure Incident Portal is a web portal for employees to report any security incidents. Employees use this portal to report any incidents and analysts to review the reported incidents, investigate and resolve them. Sensitive data like reported incidents is protected and can only be accessed based on roles like analysts and admin. Employees are restricted to their own data and cannot view other reported incidents.

## Planned Features
- Employee: Employees can create, view and edit their own security incident.
- Analyst: View all incidents, update status and investigate.
- Admin: Manage users accounts and roles, delete incidents and view the audit logs
